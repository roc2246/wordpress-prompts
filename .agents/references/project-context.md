# Project Context

Project: Reusable WordPress Development Toolkit

Purpose:
A portable baseline for custom WordPress themes and site-specific WordPress work that can be adapted across brands, industries, clients, and internal projects.

Current Goals:
- Build reusable, maintainable theme components.
- Keep presentation and durable business functionality in the correct WordPress layer.
- Maintain a clean SCSS and JavaScript asset architecture.
- Follow WordPress security and accessibility standards.
- Keep the toolkit portable across projects and AI coding assistants.

Primary Technologies:
- PHP / WordPress
- HTML
- SCSS / CSS
- JavaScript
- Optional custom plugins, MU-plugins, REST/AJAX, ACF, and build tooling when a project requires them

This repository is a baseline, not a mandate for a specific plugin stack, page builder, field framework, or build system.
