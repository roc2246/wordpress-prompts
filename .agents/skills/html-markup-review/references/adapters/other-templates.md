# Other Template Adapters

Use for Vue, Twig, Handlebars, PHP applications, static-site generators, and similar systems when no narrower adapter applies.

- Preserve directives, interpolation, loops, conditionals, partials, component props, and server-side variables.
- Distinguish host-language syntax from rendered HTML before reporting invalid markup.
- Inspect component or partial boundaries when they determine landmarks, headings, IDs, labels, or repeated content.
- Keep escaping, localization, URL generation, and data-binding behavior intact unless it is the confirmed issue.
