# Semantic HTML

- Use `header`, `nav`, `main`, `section`, `article`, `aside`, and `footer` only when their content matches the element's meaning.
- Use headings to name sections, not to style text. Keep one coherent outline and do not skip levels without a structural reason.
- Use `ul`/`ol`/`dl` for actual lists and term-definition groups.
- Use `a` for navigation or a resource URL; use `button` for an action.
- Use `form`, `fieldset`, `legend`, `label`, and suitable input types for form controls.
- Use `table` for tabular data with appropriate headers, not for layout.
- Use `figure`/`figcaption` when media has a caption or is a self-contained referenced unit.
- Keep a `div` or `span` when it is the accurate neutral grouping or styling hook.
- Check valid parent-child relationships and avoid nesting interactive controls.
